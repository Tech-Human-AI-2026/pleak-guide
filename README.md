# 인간중심의 AI — 과제 가이드

## 팀별 토의 및 개인별 보고서

### 주제

**스마트폰 AI로 나만의 개인 운영 에이전트 설계하기: 브리핑, SOP, 자동화 경계**

강의에서 다룬 AI 에이전트 운영 방식을 개인 상황에 적용한다. 핵심은 특정 앱 소개가 아니라, 스마트폰만으로 사용할 수 있는 AI를 통해 자신의 일정, 과제, 학습, 알림, 반복 업무를 어떻게 더 잘 관리할지 설계하는 것이다.

### 팀별 토의

랜덤 팀에서 아래 질문을 중심으로 토의한다.

1. 내 생활에서 AI가 매일 아침 브리핑해 주면 좋은 정보는 무엇인가
2. 내가 반복적으로 하는 일을 SOP처럼 절차화하면 무엇이 좋은가
3. AI에게 맡겨도 되는 일, 초안만 맡길 일, 맡기면 안 되는 일은 무엇인가
4. 스마트폰 AI를 쓸 때 개인정보, 과제 윤리, 의존성 문제는 어떻게 줄일 수 있는가

### 개인별 보고서

각자 자신의 상황에 맞춘 **개인 운영 에이전트 설계 보고서**를 작성한다.

보고서에는 아래 항목을 포함한다.

1. 나의 현재 상황: 수업, 과제, 아르바이트, 동아리, 취업 준비 등
2. AI 아침 브리핑 예시: 오늘 우선순위, 마감, 리스크, 준비물
3. 나만의 SOP 1개: 반복 업무 하나를 AI가 이해할 수 있는 절차로 정리
4. 자동화 경계표: 자동화 가능 / 사람 승인 필요 / 자동화 금지
5. 기대 효과와 한계: 실제로 도움이 될 점과 조심해야 할 점

### 제출

- 팀 토의 후 각자 개인별 보고서를 작성한다.
- 보고서는 각자의 GitHub repository에 업로드한다.
- 제출 repository 이름은 **`hermes-` prefix**로 시작해야 한다.
- 예시: `hermes-personal-agent`, `hermes-study-agent`, `hermes-life-ops`
